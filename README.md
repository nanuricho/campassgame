# 모눈 컴퍼스 — 설치형 앱 파일 묶음

모눈종이 위에서 컴퍼스·종이 띠·자로 원을 그려 보는 수학 도구입니다.
이 폴더를 웹에 올리면 태블릿·크롬북·컴퓨터에 **앱으로 설치**할 수 있고, 설치한 뒤에는 **인터넷 없이도** 열립니다.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 앱 이름·아이콘·색 (설치에 필요) |
| `sw.js` | 오프라인 실행 (한 번 열면 파일을 기기에 저장) |
| `icons/` | 앱 아이콘 |
| `fonts/` | 제목·숫자 글꼴 (인터넷 없이도 같은 모습) |

> 폴더 구조를 바꾸지 말고 **통째로** 올려 주세요.

## 1. 웹에 올리기 (둘 중 하나)

### 가장 쉬운 방법 — Netlify Drop
1. https://app.netlify.com/drop 에 들어가 (무료 가입)
2. 압축을 푼 **폴더를 통째로** 화면에 끌어다 놓습니다.
3. 잠시 뒤 `https://○○○.netlify.app` 주소가 생깁니다. 이 주소가 앱 주소예요.
   (사이트 설정에서 주소 이름을 바꿀 수 있어요.)

### GitHub Pages
1. GitHub에 새 저장소(public)를 만들고, 이 폴더 안의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root)** 를 고르고 저장합니다.
3. `https://아이디.github.io/저장소이름/` 주소가 앱 주소예요.

> `https://` 주소여야 설치와 오프라인 실행이 됩니다.
> 내 컴퓨터에서 `index.html`을 더블클릭해도 그리기는 되지만, 설치·오프라인은 안 돼요.

## 2. 기기에 설치하기

| 기기 | 방법 |
|---|---|
| 크롬북·윈도우·맥 (크롬/엣지/웨일) | 주소창 오른쪽의 **설치 아이콘**, 또는 앱 위쪽의 **‘앱 설치’** 버튼 |
| 안드로이드 태블릿·휴대폰 (크롬) | ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가** |
| 아이패드·아이폰 (사파리) | 공유 버튼 → **홈 화면에 추가** |

학교 크롬북은 관리자가 구글 관리 콘솔에서 이 주소를 **웹 앱으로 일괄 설치**할 수도 있어요.

## 3. 쓰는 법에서 달라진 점 (claude.ai 버전과 비교)

- **PNG 저장**: 컴퓨터는 ‘다운로드’ 폴더로 바로 저장돼요. 태블릿·휴대폰은 **공유 창**이 떠서 ‘사진에 저장’·‘파일에 저장’을 고를 수 있어요. 공유가 안 되면 그림이 크게 뜨니 꾹 눌러 저장하세요.
- **영역 잘라 저장**: 저장 카드에서 ‘영역’을 누르고 종이 위에 손가락으로 네모를 그리면, 그 네모 안만 잘라 저장돼요.
- **따라 그리기(예시 코드)**: 그대로 됩니다. 선생님이 ‘예시 코드 복사’ → 학생이 ‘코드 붙여 넣기’.
- **출발 그림**: 앱은 빈 종이에서 시작해요. 출발 그림을 정하는 버튼은 claude.ai에서만 되는 기능이라 없어요. 예시를 나눌 때는 ‘따라 그리기’의 예시 코드를 쓰세요.
- 그리던 그림은 그 기기·그 브라우저에 자동으로 남아요.

## 4. 고쳐서 다시 올릴 때

1. 파일을 고친 뒤, `sw.js` 맨 위의 `VERSION = "mogeun-compass-v3"` 숫자를 `v4`, `v5`… 로 올립니다.
2. 같은 곳에 다시 올리면, 설치된 앱도 다음에 인터넷이 될 때 새 버전을 받습니다. (한 번 껐다 켜면 반영돼요.)

### 출발 그림 바꾸기 / 없애기
`index.html`에서 `<script type="application/json" id="startScene">` 줄을 찾아
- 없애려면 그 안의 내용을 `null` 로 바꿉니다.
- 바꾸려면 claude.ai 버전에서 그림을 그리고 ‘출발 그림 코드 복사’로 받은 코드를 넣습니다.
